# 🚀 QUICK START GUIDE - EFPT_AMS

**Get up and running in 5 minutes!**

---

## 📍 STEP 1: Access the System

**URL:** `http://localhost/EFPT_AMS`

Open in your browser (Chrome, Firefox, Safari)

---

## 🔑 STEP 2: Login

**Username & Password:**
- Ask your System Administrator for credentials
- Enter username & password
- Click **"Login"**

**First time?** Use demo credentials from `README.md` (Section 4), then ask your Department Head for initial credentials

## 🎯 STEP 4: Choose Your Path

### **IF YOU'RE A REGULAR USER:**

1. **I want to REQUEST equipment:**
   - Click **"Assets"** → **"Request Asset"**
   - Select what you need
   - Explain why you need it
   - Submit
   - ⏳ Wait 2-5 days for approvals
   - 📦 Pick up from store when approved

2. **I want to see MY ASSETS:**
   - Click **"Assets"** → **"My Assets"**
   - See all equipment assigned to you

3. **I want to RETURN equipment:**
   - Click **"Operations"** → **"Return Asset"**
   - Select what to return
   - Note the condition
   - Submit
   - ⏳ Wait for approval & pickup

---

### **IF YOU'RE A DEPARTMENT HEAD:**

1. **I need to APPROVE requests:**
   - Click **"Requests"** → **"Pending Approvals"**
   - See list of requests from my team
   - ✅ Click "Approve" or ❌ "Reject"
   - Add comment if needed

2. **I want to see DEPARTMENT assets:**
   - Click **"Assets"** → **"My Department Assets"**
   - See all equipment in my department

3. **I need to TRANSFER assets:**
   - Click **"Operations"** → **"Transfer Asset"**
   - Select asset & destination
   - Wait for other dept head approval

---

### **IF YOU'RE A STORE MANAGER:**

1. **I need to ADD new equipment:**
   - Click **"Assets"** → **"Add Fixed Asset"** (or Current)
   - Enter asset details
   - **Auto-features:**
     - Asset code auto-generates from name ✨
     - Store metadata auto-fills ✨
   - Click **"Save"**

2. **I need to CHECK inventory:**
   - Click **"Assets"** → **"View Stock"**
   - See what's available
   - Check stock levels

3. **I need to ISSUE equipment:**
   - Click **"Requests"** → **"Approved Requisitions"**
   - See approved requests
   - Generate voucher (Model 22)
   - Give to user

---

### **IF YOU'RE AN ADMIN:**

1. **I need to MANAGE users:**
   - Click **"Admin"** → **"Manage Users"**
   - Add / Edit / Delete users
   - Assign roles

2. **I need to MANAGE permissions:**
   - Click **"Admin"** → **"Role Permissions"** ⭐ (PROFESSIONAL UI)
   - Set what each role can do
   - Save changes

3. **I need to VIEW EVERYTHING:**
   - Click **"Reports"** → Choose report type
   - See system-wide data

## 💡 PRO TIPS

✅ **Do:**
- Fill all fields marked with red *
- Use meaningful descriptions
- Respond to approvals quickly
- Be honest about asset condition
- Check "Approval Tracking" for status updates

❌ **Don't:**
- Leave required fields blank
- Forget to submit forms
- Ignore approval requests (delays others)
- Lie about asset condition
- Lose your password (tell admin!)

## 🆘 COMMON ISSUES

**"I can't find a page"**
→ Check sidebar menu, should be there

**"My request disappeared"**
→ Check "Approval Tracking" tab

**"Asset code error"**
→ Let system auto-generate OR type unique code

**"Store info not showing"**
→ Refresh page or re-select store

**"Can't see certain pages"**
→ Your role doesn't have permission (ask admin)
